# Security

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Until a dedicated security contact is published, report suspected vulnerabilities privately to the repository owner through GitHub.

## Scope

ATENA is a decision-support service for AI agents. It is not a diagnostic or emergency-medical system.

Production integrations should avoid sending unnecessary sensitive personal data. Calling agents remain responsible for authorization, privacy, user consent, and final actions.
